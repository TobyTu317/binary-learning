# 8-Bit 二進位互動實驗室 (Binary Interactive Lab)

一個輕量、現代、零環境依賴的 8 位元（0 ~ 255）二進位與十進位轉換教學互動網頁。
改編自 GeoGebra 互動教學課件（`Binary.ggb`），保留了經典可愛的手繪拉桿開關，並升級為現代化響應式介面（RWD）、純程式碼 Web Audio 擬真音效與完整的三大教學模式。

🔗 **線上展示網址**：[https://tobytu317.github.io/binary-learning/](https://tobytu317.github.io/binary-learning/)

---

## 🌟 核心功能特色

1. **8 位元拉桿面板（8-Bit Levers）**：
   - 橫跨 $2^7 \sim 2^0$（128, 64, 32, 16, 8, 4, 2, 1）。
   - 擬真開關切換與機械點擊音效（純 Web Audio API 合成，無外部音效檔依賴）。
   - 即時計算十進位總和、二進位位元組與十六進位（Hex）。
   - 支援鍵盤快捷鍵（數字鍵 `1` ~ `8` 直接撥動對應拉桿）。

2. **三大教學模式**：
   - **模式一：自由探索**：自由撥動開關，支援「全部歸零」、「全部設為 1」、「反轉位元 (NOT)」與「加權展開式（$1\times 128 + 0\times 64 + \dots$）」即時動態數學呈現。
   - **模式二：十進位轉二進位**：提供數值輸入與雙向滑桿，以「貪婪減法」逐步展示分解為各個權重的演算法步驟。
   - **模式三：隨機測驗挑戰**：自動產生 0 ~ 255 題目，挑戰學生的二進位換算速度，附帶提示功能、連續答對題數記錄與彩帶慶祝效果！

3. **使用者友善體驗**：
   - 支援深色模式（Dark Mode）與淺色模式（Light Mode）一鍵切換。
   - 支援手機、平板與電腦全螢幕自適應排版。
